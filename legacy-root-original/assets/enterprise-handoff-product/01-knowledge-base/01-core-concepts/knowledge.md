# Core Concepts - Knowledge Base

## Definiciones ejecutivas

- Image: paquete inmutable con app + runtime + dependencias.
- Container: instancia en ejecución de una image.
- Registry: repositorio versionado de images para promoción y rollback.
- Pipeline: secuencia automatizada desde commit hasta despliegue validado.
- Artifact: salida de stage consumida por stages posteriores.

## Valor para enterprise

- Estandariza entregas entre equipos y stacks.
- Disminuye error humano y dependencia de personas clave.
- Aumenta trazabilidad y auditabilidad de cambios.
