# 09 Asset Factory

Plantillas para crear activos prácticos por cliente y por iniciativa.

## Estructura

- `01-client-case-template/`: caso de estudio por cliente.
- `02-playbook-template/`: plan de implementación end-to-end.
- `03-runbook-template/`: operación, incidentes y rollback.
- `04-deck-template/`: presentación ejecutiva/técnica.
- `05-talk-track-template/`: guion de voz por slide.
- `06-checklists/`: listas de verificación reutilizables.
- `07-kpi-scorecards/`: métricas de baseline y evolución.

## Uso rápido

1. Copiar la carpeta plantilla.
2. Renombrar con `client-name` y fecha.
3. Completar secciones obligatorias.
4. Versionar cambios en git.
