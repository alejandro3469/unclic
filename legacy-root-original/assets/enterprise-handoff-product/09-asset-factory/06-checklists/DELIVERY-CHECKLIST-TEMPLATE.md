# Delivery Checklist Template

## Antes de implementar
- [ ] Alcance y objetivos aprobados
- [ ] Inventario técnico completo
- [ ] Riesgos principales identificados

## Durante implementación
- [ ] Pipeline base funcional
- [ ] Quality gates activos
- [ ] Registry y tags definidos
- [ ] Deploy automatizado en entorno objetivo

## Antes de handoff
- [ ] Runbook validado
- [ ] Checklist operativo validado
- [ ] Capacitación completada
- [ ] KPI baseline registrado
