# Intake to Assets Mapping Guide

## Objetivo
Convertir el intake en artefactos listos para ejecución y presentación.

## Mapeo recomendado

- Intake Form -> `11-example-generic-client/01-case-study/`
- Intake Summary -> `11-example-generic-client/02-playbook/`
- Operación/Incidentes -> `11-example-generic-client/03-runbook/`
- Objetivos/KPIs -> `11-example-generic-client/07-kpis/`
- Mensaje comercial -> `11-example-generic-client/04-deck/` y `05-talk-track/`

## Flujo de trabajo
1. Completar intake.
2. Redactar summary.
3. Poblar caso/playbook/runbook/KPI.
4. Generar deck y talk-track para sesión de validación.
