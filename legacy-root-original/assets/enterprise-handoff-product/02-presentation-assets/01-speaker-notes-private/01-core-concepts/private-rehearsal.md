# 01 Core Concepts - Notas Privadas

## Mensaje

Alinear lenguaje: si no definimos image/container/registry/pipeline desde negocio, cada equipo interpreta distinto y se rompe la ejecución.

## Puntos de explicación

- Image = blueprint inmutable.
- Container = ejecución aislada y portable.
- Registry = control de versiones desplegables.
- Pipeline = estándar de entrega.
- Artifact = evidencia transferible entre etapas.

## Cierre

"Cuando normalizamos estos conceptos, normalizamos velocidad y confiabilidad."
