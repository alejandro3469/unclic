# 03 Container Registry - Notas Privadas

## Mensaje

Sin registry, no hay trazabilidad real de despliegue.

## Puntos de explicación

- Tag por commit para auditoría y rollback.
- Tags de entorno para promoción controlada.
- Scan previo a promoción para reducir riesgo de seguridad.

## Cierre

"Registry convierte release en proceso auditable, no en suposición."
