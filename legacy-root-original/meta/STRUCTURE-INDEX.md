# Estructura Organizada

## references/
Material fuente y de consulta.

- `references/book-original/chapters/` -> código original por capítulo (`chapter2` ... `chapter14`)
- `references/book-original/reference-text/_book_reference_txt/` -> referencia textual completa del libro
- `references/book-original/docs/` -> documentación original del repo del libro (`README.md`, `SECURITY.md`)

## assets/
Activos creados para producto y presentación.

- `assets/enterprise-handoff-product/` -> knowledge base, decks, talk tracks y documentos de handoff

## meta/
Índices y archivos de organización del workspace.

- `meta/STRUCTURE-INDEX.md` -> este mapa

## raíz

- `.gitignore`
- `.idea/` (configuración del IDE)
- `references/`
- `assets/`
- `meta/`
