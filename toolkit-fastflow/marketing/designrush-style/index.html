How To Use ChatGPT for UI/UX Design (With Sample Prompts)

Transforma tu proceso de diseño UI/UX con técnicas concretas para ideación más rápida, mejor alineación entre equipos y entregables consistentes.

How To Use ChatGPT for UI and UX Design: Key Points

  • IBM iX comprimió un sprint de diseño de dos semanas a dos días usando IA generativa.
  • Shopthemer creó 12 personas distintas y mejoró su targeting en eCommerce.
  • ChatGPT acelera flujos, copy, documentación y reduce iteraciones.

1. User Research and Persona Development

ChatGPT acelera una fase lenta: convertir feedback cualitativo caótico en hipótesis accionables. Úsalo para extraer insights y construir borradores de personas listos para iterar.

1.1 Generate Empathy-Driven Personas From Interviews

Convierte entrevistas en perfiles claros con metas, fricciones, hábitos y motivaciones. 

You are a UX researcher for a budgeting app.
Create one persona using interview notes.
Include demographics, daily habits, goals, pain points,
preferred platforms, and a quote.

1.2 Summarize Survey Responses Into Themes

Agrupa respuestas abiertas en 3-5 temas para priorizar rápidamente. 

Summarize open-text survey responses into 3-5 themes.
For each theme provide:
- short label
- sentiment summary
- optional quote

1.3 Brainstorm Features Based on User Pains

Convierte dolores en ideas de producto evaluables durante discovery. 

Based on these pain points, suggest 5 features.
For each feature include:
- name
- pain addressed
- experience improvement

1.4 Compare or Refine Existing Personas

Encuentra solapamientos, vacíos y contradicciones antes de escalar diseño y copy.

1.5 Extract Jobs-To-Be-Done From Raw Feedback

Pasa de “peticiones de features” a necesidades reales con formato JTBD.

2. UX Writing and Interface Copy

El texto en UI suele llegar tarde. ChatGPT te ayuda a crear borradores de tooltips, modals, labels y mensajes de error con tono consistente.

  • Create tooltips, onboarding text, and modals
  • Generate button, label, and menu text options
  • Rewrite error messages for clarity and tone
  • Adapt voice and tone based on persona type

3. Wireframing and Content Structuring

Antes del high-fidelity puedes validar jerarquía, bloques y narrativa de pantalla sin bloquearte por el copy final.

  • Generate section ideas based on page goals
  • Suggest layout hierarchies for key screens
  • Draft component descriptions for design systems

4. Journey Mapping and Usability Testing

Convierte pruebas y transcripciones en aprendizajes accionables en minutos y no en días.

  • Map key user flows based on intent
  • Draft moderated and unmoderated testing scripts
  • Analyze feedback from recordings or transcripts

5. Developer Handoff and Design Documentation

Documenta componentes, estados, edge cases y accesibilidad para reducir fricción en handoff entre diseño, PM y desarrollo. 

You are preparing developer handoff for a scheduling app.
Generate an annotated spec with:
- components
- states
- rationale
- accessibility considerations

Where ChatGPT Falls Short

  • No toma decisiones de diseño por sí solo.
  • Depende de prompts con contexto específico.
  • No valida con usuarios reales.
  • Puede alucinar o contradecirse.
  • No entiende tu voz de marca sin ejemplos.

Guidelines for Using ChatGPT in UI/UX Design

  • Especifica contexto, segmento, tono y restricciones.
  • Usa los resultados para explorar, no para decidir final.
  • Incluye ejemplos de feedback o contenido real.
  • Recorta repeticiones y relleno.
  • Define reglas de voz y revisión de accesibilidad.
  • Siempre cierra con feedback loops de equipo y usuarios.
