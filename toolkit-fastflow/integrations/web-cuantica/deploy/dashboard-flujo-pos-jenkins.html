Flujo del pipeline (solo el paso 1 es manual)

Paso 1 — Manual
Hacer commit
En tu repo pos-online: git add . && git commit -m "..." && git push. El resto lo dispara Jenkins.
Abrir repo (configurable)
→
Paso 2
Build y tests
Maven: compile, test, package. Se ejecuta en Jenkins tras el commit.
Ver en Jenkins → Console Output
→
Paso 3
Imagen y Registry
Build de imagen Docker y push al registry (si está configurado).
Abrir catálogo Registry
→
Paso 4
Aplicación POS
App desplegada (local o en AWS). Comprueba health aquí.
Abrir aplicación
