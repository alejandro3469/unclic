1. Echar a andar (orden: POS → Jenkins)

Paso 1 — Ejecutar en la raíz del repo pos-online

POS Online

mvn spring-boot:run -Dspring-boot.run.profiles=local
Abrir POS Health

Puerto por defecto: 8111. Tras arrancar, abre el enlace «Abrir POS».

Paso 2 — En local o en AWS

Jenkins

java -jar jenkins.war (o docker run -p 8080:8080 jenkins/jenkins:lts)
Abrir Jenkins

En AWS: Jenkins ya corre en la EC2. Usa la URL que guardes abajo (ej. http://<IP>:8080).

Opcional — Registry local

Registry

docker run -d -p 5000:5000 --name registry registry:2
Catálogo

Para que el pipeline haga push de la imagen.

2. URLs (local o AWS)

Por defecto: localhost. Si desplegaste en AWS con Terraform, pega la IP pública de tu EC2 y guarda. Todos los enlaces de esta página usarán estas URLs.

Tras terraform apply, usa http://<jenkins_public_ip>:8080
