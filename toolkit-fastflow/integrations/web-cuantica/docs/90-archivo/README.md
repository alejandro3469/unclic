# Archivo y material de referencia

Aquí van documentos **largos o poco cambiantes**: capítulos tipo “libro”, planes de producto/demo, propuestas comerciales, copias para Word, historial de recuperación desde Git, y el índice por tecnología / tutorial visual.

- **Raíz de `90-archivo/`:** capítulos AWS, planes, métricas, índices maestros, etc.
- **`copia/`:** textos explicativos (p. ej. qué es POS + FastFlow).
- **`historial/`:** cómo recuperar `.md` que solo existen en commits viejos.
- **`listos-para-word/`** y **`propuestas/`:** borradores y entregables de texto.

Para operar el laboratorio día a día, prioriza **`10-guia-unica/`** y **`20-operaciones/`** (ver **`../README.md`**).
