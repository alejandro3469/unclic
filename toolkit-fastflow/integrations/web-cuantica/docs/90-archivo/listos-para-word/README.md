## Cómo usarlos en Word y exportar a PDF

1. Abre el archivo `.md` en el editor (Cursor, VS Code, o vista previa que permita copiar).
2. Selecciona todo el contenido (Cmd+A / Ctrl+A) y copia (Cmd+C / Ctrl+C).
3. Ve a **Word Online** (office.com → Word → documento en blanco) o Word de escritorio.
4. Pega (Cmd+V / Ctrl+V). Word suele conservar títulos y tablas; si alguna tabla se desalinea, ajusta columnas a mano.
5. Opcional: aplica estilos de Word (Título 1, Título 2) a los encabezados para el índice automático.
6. **Archivo → Descargar como → PDF** (Word Online) o **Archivo → Guardar como → PDF** (Word de escritorio).

## Qué incluyen las propuestas (común)

- **Variables del proyecto:** qué se considera en la estimación (entregables, rondas de revisión, disponibilidad de material, requisitos de seguridad, etc.); lo no especificado queda fuera de alcance.
- **Stack y buenas prácticas:** Git/Gitea, Jenkins (pipeline as code), Maven, Docker, Terraform cuando aplica; código versionado, pipeline repetible, pruebas en entorno definido, alcance por escrito.
- **Valor aportado:** expertise, tiempo, infraestructura y metodología (FastFlow); calidad verificable en entorno de despliegue acordado; transparencia y cláusulas para seguridad jurídica.
