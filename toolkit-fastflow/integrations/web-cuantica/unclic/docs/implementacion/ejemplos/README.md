# Ejemplos TypeScript (plantilla)

Copia fragmentos a `services/api/src/` e integra en `createApp()` o rutas modulares.

- Añade dependencias (`stripe`, `amqplib`) cuando actives cada pieza.
- Añade tests (Vitest) y entradas en `openapi/openapi.yaml`.
- Ejecuta `npm run typecheck` en `services/api`.
