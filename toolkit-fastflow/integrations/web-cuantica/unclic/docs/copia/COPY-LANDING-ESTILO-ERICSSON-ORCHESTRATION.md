## Bloque 1 — Despliega tan rápido como hagas commit

**Headline**  
Despliega tan rápido como hagas commit.

**Subheadline**  
Deja que el pipeline as code transforme tu entrega.

**Cuerpo**  
El pipeline como código reduce la complejidad al versionar el flujo en Git y eliminar pasos rígidos o manuales. Te permite que cada commit dispare build, tests y despliegue de forma repetible, y que los entregables se verifiquen en el entorno acordado.

La gestión del alcance (alcance por escrito, revisiones acotadas) te permite concentrarte en lo que quieres lograr — el resultado acordado — sin sorpresas en plazos ni facturación. Cerramos el círculo con entrega verificada y documentación en repo.

Te cubrimos con pipeline as code (Jenkinsfile), Jenkins, Gitea, registry opcional y despliegue en el entorno acordado.

## Bloque 2 — Beneficios clave del pipeline automatizado

**Headline**  
Beneficios clave del pipeline automatizado

**Intro**  
Pasar a un flujo automatizado y repetible no es solo un objetivo sino una necesidad si quieres mantener competitividad y reducir lead time. Con pipeline as code puedes:

- **Simplificar operaciones** automatizando build, tests y despliegue, optimizando el uso del repositorio y la visibilidad del flujo en Jenkins.
- **Mejorar la entrega** con ajustes del pipeline versionados (Jenkinsfile) que mantienen un flujo estable y repetible.
- **Abrir espacio para innovar** al tener el flujo documentado y bajo control, con menos tiempo perdido en despliegues manuales.

## Bloque 3 — Funcionalidades para un flujo automatizado

**Headline**  
Funcionalidades clave para un flujo automatizado

**Intro**  
Nuestras soluciones de pipeline están pensadas para simplificar operaciones, automatizar procesos y mejorar la entrega mediante:

- **Alcance y revisión** — Alcance por escrito, número de revisiones incluido; lo adicional por anexo.
- **Pipeline y calidad** — Build, tests y despliegue en un solo flujo; tests automáticos en cada ejecución cuando aplica.
- **Automatización cerrada** — Commit → build → test → package → deploy (y opcional registry) sin pasos manuales intermedios.
- **Visibilidad en tiempo real** — Estado del pipeline y logs en Jenkins; trazabilidad commit → artefacto → despliegue.
- **Agnóstico de stack** — Maven, Docker, Git; soporte para EC2, Nginx, opcional Kubernetes según alcance.
- **Alineado con estándares** — Jenkinsfile declarativo, pipelines multibranch, documentación en repo.
