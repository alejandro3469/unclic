## Resumen de bloques para la homepage

1. **Hero** — “Deja de entregar a ciegas” + visibilidad + CTA.  
2. **Backed by** — Una línea de confianza (sin logos de clientes).  
3. **Estadísticas** — Pipeline desde 1 sprint, lead time en horas, 2 rondas, demo en minutos.  
4. **Tu elección** — Value prop en 2–3 frases + CTA.  
5. **Obtener estimación** — “Mira en cuánto tiempo puedes tener pipeline” + formulario o enlace a cotización.  
6. **Testimonial** — “Nuestros clientes entregan más rápido” + cita.  
7. **Journey** — Día 1 / Semana 1 / Sprint 1 (solicitar demo → probar → pipeline o cotización).  
8. **Use cases** — Pipeline, Despliegue, Sitios, Consultoría (+ Recursos).  
9. **Footer** — Casos de uso, Empresa, Contacto, Legal, línea técnica.

*Todo sin prometer cashback, créditos AWS ni gestión de gasto SaaS; sí pipeline, demo, alcance claro y cotización.*
