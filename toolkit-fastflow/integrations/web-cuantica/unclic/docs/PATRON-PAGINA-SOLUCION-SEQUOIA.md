## 3. Investor Solutions

**Referencia:** [sequoia.com/solutions/investors](https://www.sequoia.com/solutions/investors/)

Página orientada a **quienes invierten** (VC, PE, board) y a **portcos**: datos, benchmarks y lenguaje común para decisiones. En UnClic el paralelo es **due diligence técnica**, **madurez de CI/CD** y **un hub demostrable** para comités.

| Bloque Sequoia | Equivalente UnClic |
|----------------|---------------------|
| **Eyebrow** `INVESTOR SOLUTIONS` | **SOLUCIONES PARA INVERSORES & BOARD** o **CI/CD BAJO LENTE DE INVERSIÓN** |
| **H1** “Gain a clear advantage helping your portcos hit their mark” | **Ventaja clara para que tus portcos cumplan plan técnico y de entrega** |
| Párrafo trusted partner + data + lens | Partner con **demos vivas**, diagramas (Cloudcraft) y criterios claros de pipeline; mismo lenguaje para fondo y operación |
| Métricas (CLIENTS, NPS…) | Demos accesibles, portcos atendidos (si aplica), años de práctica |
| **“Investor guidance for on-point portco execution”** | **Criterios para ejecutar bien el plan de despliegue en cada portco** |
| Párrafo VC/PE + portfolio | Cómo ayudamos a **fondos**, **equipos de value creation** y **CTO/CIO de portcos** |
| **3 tarjetas** For VC / For PE / For Portfolio Companies | **Para Venture Capital** (talent/tech partners) · **Para Private Equity** (sinergias post-M&A, integración de repos) · **Para portcos** (alineación con board: releases, riesgo, coste cloud) |
| **“Increase shareholder value through smarter people spend”** | **Más valor vía menos riesgo en releases y coste predecible de entrega** |
| Párrafo comp partner + holistic | Pipeline y arquitectura como **sistema**: no solo Jenkins suelto |
| Dos visuales (mesa inversores, dashboard) | Captura **hub UnClic**, **Jenkins**, **diagrama multi-región** |
| **“Align compensation to market…”** (sección larga) | **Alinear despliegue al plan de negocio**: ramas, entornos, rollback, compliance básica |
| **“Transform benefits complexity…”** (segunda columna larga) | **Deuda técnica de CI/CD → palanca**: menos incidentes, más frecuencia de release segura |
| **“Solutions built to power investor-portco synergy”** | **Ofertas por perfil** con bullets (como VC / PE / Portco en Sequoia) |
| Sub-bloques VC: bullets (Talent Partners, benchmarks, OS for Investors) | **VC:** línea directa a assessment de pipeline · informe tipo health-check · acceso a hub demo · benchmarks de madurez (definir los tuyos) |
| Sub-bloques PE + Portco | **PE:** integración post-fusión de Git/Jenkins · unificar registry · due diligence pre-cierre · **Portco:** checklist release, documentación para auditoría |
| Testimonios MID-SIZE / ENTERPRISE / SMB | Mismo patrón: portco mediano, grupo grande, equipo PE operativo |
| CTA “Start looking at people spend through the investor lens” | **Mira el riesgo de entrega con lente de inversor** — Talk to Advisor → **Solicitar briefing técnico** |

## 4. Platform Solutions (Sequoia OS)

**Referencia:** [sequoia.com/solutions/platform](https://www.sequoia.com/solutions/platform/)

Mensaje central: **un solo sistema** unifica datos dispersos y da **claridad, análisis y control**. En UnClic el paralelo es el **hub + stack integrado** (Git, Jenkins, registry, AWS, diagrama) como “OS” de la entrega — no herramientas sueltas.

**Stack Docker (mensaje técnico reutilizable):** build con Docker → artefacto **imagen OCI** → **registry** (mismo estándar que la [imagen oficial `registry`](https://hub.docker.com/_/registry)) → deploy. Detalle y enlaces oficiales: [DOCKER-Y-REGISTRY-UNClic.md](DOCKER-Y-REGISTRY-UNClic.md).

| Bloque Sequoia | Equivalente UnClic |
|----------------|---------------------|
| **Eyebrow** `PLATFORM SOLUTIONS` | **SOLUCIONES DE PLATAFORMA** o **UNClic OS** *(nombre interno, no marca registrada)* |
| **H1** “Activate your people strategy with Sequoia OS™” | **Activa tu estrategia de entrega con un solo stack visible** |
| Hero + producto unificado HRIS/payroll/equity/benefits | **Unifica repo, pipeline, artefactos e infra** en un hub: ves commits, builds, imágenes y arquitectura en un solo lugar |
| Métricas **EMPLOYEES SERVED / ADOPTION / APP RATING** | Métricas propias verificables: p. ej. **demos activas**, **% builds exitosos**, **enlaces del hub usados** (solo si las tienes) |
| **“Centralize your comp and benefits on one platform”** | **Centraliza pipeline y despliegue en una vista coherente** |
| Párrafo purpose-built / operating system | La landing + hub actúan como **sistema operativo de lectura** para due diligence y alineación equipo–liderazgo |
| **4 pilares con icono** COMPENSATION / PEOPLE / BENEFITS / ANALYTICS | **PIPELINE** (Jenkinsfile, ramas, ciclos) · **ORG & REPOS** (Gitea, equipos, permisos) · **ARTEFACTOS** (registry, tags, rollback) · **OBSERVABILIDAD** (Cloudcraft, regiones, coste/riesgo visual) |
| Imagen “data and insights” | Captura **diagrama Cloudcraft** o **dashboard Jenkins** |
| **Leverage your HR tech stack** (conectar ATS, HRIS…) | **Encaje con tu stack**: Git existente, AWS, Docker; el hub **enlaza** lo que ya tienes |
| Integración visual + colaboración | **Devs + DevOps + leads** comparten el mismo mapa y los mismos enlaces demo |
| **Know your sensitive data is safe** + Trust Center | **Pipeline y secretos**: buenas prácticas, HTTPS, credenciales fuera del repo; enlace a doc de seguridad / Trust si existe |
| **“Comprehensive platform tools”** + grillas por módulo | Tablas por área: *Pipeline* (multibranch, webhooks, logs) · *Registry* (push, tags) · *Deploy* (EC2, rollback) · *Docs* (arquitectura viva) |
| Testimonios (ops, HR enterprise, SMB app) | Equipos que **vieron el hub** y redujeron fricción con auditores o entre squads |
| CTA “See your people strategy in high definition” / **See a Demo** | **Ve tu estrategia de entrega en alta definición** → **Ver el hub** / `#hub-demos` |
