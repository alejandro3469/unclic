# Guía: estructurar tu LinkedIn **personal** (inspiración tipo página empresa Sequoia)

La [página de empresa de Sequoia en LinkedIn](https://www.linkedin.com/company/sequoia-tpi/) está muy ordenada: **cabecera clara**, **About** sólido, **destacados**, **contenido**, **ofertas**, **cultura**, **gente**, **datos**. En un **perfil personal** no existen las mismas pestañas, pero **el orden mental** sirve: primero **quién eres en una línea**, luego **historia**, luego **prueba** (enlaces, posts), luego **trayectoria** y **credibilidad**.

**Objetivo:** que en **10 segundos** entiendan qué haces; en **1 minuto** vean prueba (UnClic, repo, artículo); en **scroll** vean coherencia (experiencia alineada al headline).

---

## 1. Mapa: empresa Sequoia → tu perfil personal

| Bloque tipo “empresa” | Equivalente en **perfil personal** | Qué poner |
|------------------------|-----------------------------------|-----------|
| **Logo + portada** | Foto de perfil + **imagen de fondo (banner)** | Foto clara; banner con frase corta, stack o “Pipeline as Code · UnClic” (sin texto ilegible). |
| **Nombre + tagline** (industria, ciudad, followers) | **Nombre** + **Titular (Headline)** | Headline = tu “producto” en una línea: rol + nicho + 2 tecnologías. No solo “Web developer”. |
| **Botón Message** | Abierto a mensajes / **Open to** | Activa *Open to work* o *Providing services* según tu caso. |
| **About us** (overview largo) | **Acerca de** | 3–5 párrafos: qué haces, para quién, stack, logro concreto, CTA (“escribirme para…”). |
| **Website + Specialties** | **Sitios web** + **Habilidades** (top 3 visibles) | Enlace a **UnClic** como portfolio; skills alineadas al headline. |
| **Featured** | **Destacados** | 3 ítems: post propio, enlace al hub UnClic, PDF o GitHub. |
| **Posts / Updates** | **Actividad** | Publicar o reaccionar con criterio; 1–2 posts/mes mejor que silencio total. |
| **Jobs** | **Buscando empleo** / **Servicios** | Roles objetivo claros; o “ofrezco asesoría CI/CD” si aplica. |
| **Life + fotos** | **Voluntariado** / **Cursos** / fotos en experiencias | Opcional; solo si suma (eventos tech, charlas). |
| **People (empleados)** | **Red relevante** | Conexiones en retail, DevOps, Java — coherente con tu historia. |
| **Insights (métricas)** | **Analíticas** (solo tú) | Mira qué visitas tu perfil; ajusta headline si nadie clica. |
| **Showcase pages** | **Proyectos** + **Publicaciones** + **Patentes** (si hay) | UnClic como proyecto con descripción y URL. |

---

## 2. Orden recomendado para dejarlo fino (paso a paso)

1. **Headline** — sin genéricos; nicho + stack (ver ejemplos en [LINKEDIN-ALEJANDRO-PEREZ-PULIDO.md](LINKEDIN-ALEJANDRO-PEREZ-PULIDO.md)).  
2. **Banner** — una sola idea visual o texto corto.  
3. **Acerca de** — mismo mensaje que el headline, desarrollado; termina con llamada a la acción.  
4. **Destacados** — enlace a UnClic + 1 post + 1 recurso (doc, charla).  
5. **Experiencia** — cada puesto: 3–5 viñetas con **impacto** (qué mejoró, qué stack), no solo tareas.  
6. **Habilidades** — las primeras deben coincidir con lo que buscas (Jenkins, Docker, Spring…).  
7. **Open to** — roles y ubicaciones realistas.  
8. **Actividad** — un post cada 2–4 semanas (insight técnico, enlace a tu doc, “así monté X”).  

---

## 3. Principios copiados del “look enterprise” (sin copiar a Sequoia)

| Principio Sequoia (empresa) | Aplicado a ti |
|------------------------------|---------------|
| Tagline que no se confunde con otra marca | Headline que no suene a “cualquier dev”. |
| About con CTA al sitio | Acerca de con enlace explícito a UnClic o calendly. |
| Featured con alianzas / informes | Destacados con tu **demo viva** (hub). |
| Especialidades en lista | Skills + palabras clave que buscan reclutadores (POS, CI/CD). |
| Eventos visibles | Crea evento o comparte webinar al que vayas — señal de que estás activo. |

---

## 4. Checklist rápido (sí / no)

- [ ] Headline dice **qué** + **para qué contexto** (retail, pipeline, etc.).  
- [ ] Banner no está vacío ni es foto random.  
- [ ] Acerca de tiene **UnClic** o portfolio en el primer tercio.  
- [ ] Destacados tienen al menos **un enlace** que tú controlas.  
- [ ] Experiencia más reciente tiene **métricas o alcance** (equipo, tráfico, tiendas).  
- [ ] Foto coincide con cómo te presentarías en una entrevista en vídeo.  
- [ ] Idioma coherente (ES o EN; si mezclas, que sea intencional).
