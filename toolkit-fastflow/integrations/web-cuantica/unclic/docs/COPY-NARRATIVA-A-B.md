# Narrativa editorial UnClic (punto A → punto B)

## Regla

- **A:** situación actual (dolor, incertidumbre).
- **B:** resultado deseado (control, evidencia, velocidad).
- **Brecha:** hay muchos caminos; UnClic muestra **uno** que la cierra con stack documentado (docs oficiales de cada herramienta + experiencia en FastFlow).

## Tono

- Frases cortas; una idea por bloque.
- Detalles como **pistas** (enlace a doc oficial, variable de entorno, “ver repo”), no manuales largos en la UI.
- Evitar saturar: la profundidad vive en `docs/` del repo y en conversación.

## Dónde vive el copy

- Principal: `lib/copy.ts`
- Precios: `lib/copy-pricing.ts`
- Presupuesto OSS: `lib/copy-presupuesto-oss.ts`
- Lead correo: `lib/copy-lead-email.ts`

Al añadir secciones, mantener el mismo marco A/B en título + una línea de apoyo.
