# Capturas de arquitectura (Cloudcraft)

1. Genera una captura fiel del diagrama (logueado en Cloudcraft): ver **`docs/VISUALES-CLOUDCRAFT-Y-DEMOS-REPO.md`**.
2. Guarda como `cloudcraft-demo.webp` o `cloudcraft-demo.png`.
3. Define en build:

   `NEXT_PUBLIC_CLOUDCRAFT_STATIC_IMAGE=/images/architecture/cloudcraft-demo.webp`

Los archivos de imagen en esta carpeta pueden committearse; actualízalos cuando cambie la infra.
