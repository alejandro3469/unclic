# Slide 10 - Talk Track (ES/EN)

## ES (qué decir)
El registry es nuestro control de versiones desplegables. Promoción y rollback se vuelven operaciones de referencia a tags conocidos, no acciones manuales inciertas.

## EN (what to say)
The registry is our deployable version control layer. Promotion and rollback become known-tag reference operations, not uncertain manual actions.

## Cierre sugerido
Añadimos seguridad con escaneo antes de promoción.
