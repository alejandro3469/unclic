# 02-cicd-pipeline - Contenido para Cliente

## Antes

- Deploys manuales.
- Riesgo de errores humanos.
- Baja frecuencia de release.

## Después

- Flujo estandarizado de entrega.
- Validación automática previa a deploy.
- Mayor velocidad con menor riesgo.

## Cadena de valor

`Commit -> Validación -> Artefacto confiable -> Despliegue controlado -> Verificación`
