# 01 Core Concepts

## Definiciones de trabajo

- **Image:** paquete inmutable de aplicación.
- **Container:** instancia ejecutándose de la image.
- **Registry:** repositorio central de images versionadas.
- **Pipeline:** flujo automatizado de validación y entrega.

## Beneficio directo

Un lenguaje único para todos los equipos reduce errores y acelera decisiones.
