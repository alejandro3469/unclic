# 06 Reliability and Observability - Notas Privadas

## Mensaje

Confiabilidad sin visibilidad no es sostenible.

## Puntos de explicación

- Gates: tests + lint + scan + aprobación.
- Health checks al terminar despliegue.
- Métricas y logs para operación diaria y auditoría.
- Runbooks para incidentes y rollback.

## Cierre

"La confiabilidad se diseña en el pipeline y se valida en operación."
